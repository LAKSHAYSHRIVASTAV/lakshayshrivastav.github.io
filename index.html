A/B Test Analysis — UrbanCart Checkout Redesign

Determine whether a redesigned checkout experience improved conversion.

MySQLPythonPower BIStatisticsDAX

Business Problem

Determine whether a redesigned checkout experience improved conversion.

Approach

Analyzed an A/B experiment comparing two checkout variants using conversion analysis, statistical testing, and segment-level analysis. Validated experiment quality through Sample Ratio Mismatch detection before interpreting the observed conversion difference.

Tools Used

MySQL, Python, Statistics, Power BI, DAX

Key Analysis

12.67%Variant A conversion
13.73%Variant B conversion
+1.06 ppAbsolute uplift
+8.35%Relative uplift
  • SQL experiment analysis
  • Conversion rate analysis — absolute and relative uplift
  • Statistical testing
  • Sample Ratio Mismatch detection
  • Device-level and traffic-source analysis
  • Interactive Power BI reporting

Key Findings

Variant B showed higher observed conversion, but Sample Ratio Mismatch was detected, so the experiment required further investigation before rollout.

Variant B is not presented as a confirmed winner — SRM must be resolved before any rollout decision.
