### 2. A/B Test Analysis — UrbanCart Checkout Redesign

**Business Problem**

Determine whether a redesigned checkout experience improved conversion and whether the experiment was statistically reliable.

**Tools**

- MySQL
- Python
- Power BI
- Pandas
- NumPy
- SciPy
- DAX

**Key Work**

- Conversion-rate analysis
- Variant performance comparison
- Absolute and relative uplift
- Daily performance analysis
- Device and traffic-source segmentation
- Statistical testing
- Sample Ratio Mismatch (SRM) detection
- Power BI experiment dashboard

**Key Finding**

Variant B showed higher observed conversion than Variant A, but the experiment had a detected SRM issue. Therefore, the analysis treated the observed uplift cautiously and recommended investigating the experiment imbalance before rollout.
